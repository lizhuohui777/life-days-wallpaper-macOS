# 贡献指南

在 macOS 上安装 Xcode Command Line Tools 与 Python 3。在项目目录执行 `zsh scripts/test.sh` 与 `zsh scripts/build.sh --app-only`。

测试使用临时目录和合成图片，不访问或修改实际桌面、LaunchAgents、个人日期设置。预览使用 `--preview`，也不得触发系统清理。

修改文件导入、日期计算或系统引用迁移时增加行为测试。避免引入网络、私有 API、全局偏好写入或未经许可的素材。兼容清理需维持默认关闭、范围限定及备份行为。

PR 请写明问题、最终行为、验证方式与限制。不要提交 `.app`、DMG、日志、原照片、个人配置或第三方字体。原创代码与文档贡献按项目 MIT 许可证提供；照片素材适用各自独立授权，提交前须确认拥有相应权利。
