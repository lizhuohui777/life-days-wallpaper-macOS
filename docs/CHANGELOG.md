# 更新记录

## 1.8.1-beta.1（2026-11-13，预发布测试版）

修复每天覆盖固定路径导致 macOS 缓存旧天数的问题。为内容版本生成新图片路径，通过公开接口更新每个已连接屏幕，并逐屏确认后记录成功；同一天有屏幕仍指向旧图时也会重试。加入进程锁、午夜检查和更新结果日志；兼容清理支持新路径，仅删除系统已不再引用的本程序旧图。补充跨日、多屏与实际 worker 预览回归测试。

## 1.8.0-beta.1 — 预发布测试版

- 源码、应用资源及开发文档分目录整理。
- 增加直接下载安装指引及预发布测试安装包。

## 仓库准备

- README 展示自行导入狮子照片的预览；独立附赠已清理隐私元数据的照片，程序默认背景不变。

- 添加可重复生成的应用图标。
- 添加共享逻辑与可重复运行的日期、图片隐私和迁移测试。
- 添加从源码创建完整应用的构建脚本、macOS CI 与源码导出检查。
- 清理公开照片元数据；原始照片放在仓库外私人保存。
- 添加文档、许可草案、贡献与安全说明；公开示例不含用户配置。
- 新安装默认使用中性玩家名和当天日期；已有用户设置继续读取。

## 1.7 — 本地版本

## 1.0–1.5 — 本地原型
